# HG Spatial Data changelog

## 1.0.0-rc.1 — local candidate preparation

Introduces the accepted HGSpatial.create configuration/controller API over shared
Cytoscape.js 2D and Babylon.js 3D semantics: original identity, source-only relationships,
zoom-driven clusters/bundles, selection, inspection, focus/Back, live updates, queued
events and atomic identity errors. Preserves the accepted default visualization.

Adds a maintainer-only offline deterministic archive/npm asset assembler, explicit
public-file selection, checksums and provenance. No runtime source change is included.
Adds the approved MIT LICENSE, copyright 2026 Hippogriff Technology LLC, with the full
license bound by the assembly preflight. Assembly remains blocked on name, vendor
input/inventory and governed execution evidence.
No artifact or public release currently exists.

Known limits: global renderer coexistence, synchronous hierarchy rebuilds, finite
cosmetic fidelity in 3D, incomplete browser/device/accessibility/offline/CSP and real
performance evidence. No Node/fake-engine timing is a browser support/performance claim.

No prior public version exists. Private development APIs/labs are outside SemVer
compatibility. Future migrations document replacements and preserve original source
identity; aggregate identities must not be saved as durable application records.
